# 狐隱 KOGAKURE｜專案概要與變更紀錄

> 世有百鬼，夜有萬境。循狐而入，借湯忘憂。

狐隱是 FF14 RP 店鋪的公開展示與館務管理網站。前端採 React、TypeScript、Vite，網站使用 GitHub Pages 發布；Supabase 負責登入、資料庫權限、圖片與背景音樂素材，以及受控員工帳號管理。

本文件記錄**系統變更與必要性**，不包含環境建立、部署指令或後台操作教學。程式碼具備某項功能，不代表正式資料庫已套用相關版本，亦不代表完成實際驗收。

## 功能與架構

| 領域 | 已實作內容 | 變更必要性 |
| --- | --- | --- |
| 公開網站 | 首頁、入館須知、服務、狐姬名冊、排班、茶宴、指名預約、公告及 BGM | 統一展示與手機體驗 |
| 後台管理 | 獨立管理版型及分模組權限，共 12 個管理模組 | 防止管理功能與前台混雜 |
| 狐姬名冊 | 照片、公開狀態、排序、搜尋及資料快取 | 降低名帖維護成本、改善瀏覽速度 |
| 訂單與預約 | 公開提交、受控接單、計時及歷史紀錄 | 避免展示資料與正式流程混淆 |
| 留影與留言 | 狐影留帖、領取碼及狐語迴音審核／回覆 | 區分非公開照片交付與公開留言內容 |
| 員工與帳務 | 獨立登入、權限委派、Gil 帳務及薪資紀錄 | 隔離不同職責與敏感資料 |
| 載入效能 | 非核心頁面按需載入，BGM 減少預載和背景查詢 | 縮小首頁資源、減少無效網路流量 |

## 程式碼區域

- `src/`：前台、後台、共用元件與資料介面。
- `public/images/`：網站公開展示素材。
- `scripts/`：建置輔助與自動化驗證。
- `supabase/migrations/`：資料結構、RLS 與 RPC 的版本變更。
- `supabase/functions/`：伺服器端受控功能。
- `docs/`：各模組的變更原因、影響及尚待確認的風險。

GitHub 用於存放網站原始碼及發布所需檔案；公開網站的前端程式與素材可由瀏覽器取得，因此不能包含伺服器端密鑰、員工密碼或不應公開的營運資料。資料存取仍須由後端權限保障。
