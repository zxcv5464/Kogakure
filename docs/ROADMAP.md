# 狐隱 KOGAKURE｜開發進度與規劃

最後調整：2026-11-08
工作位置：`D:\kogakure`
開發流程：**DevSpace → 本機測試（店長 Supabase）→ 推送店長 GitHub → GitHub Pages 自動發布**。

## 固定原則

- 手機版以底部五格導覽為主，按鈕易點，內容不被導航列遮擋。
- 電腦版保留完整導航與較大字體；暗色背景須確保文字對比與行距。
- 介面輕量、乾淨、精美；不依賴長時間動畫與大圖才能使用。
- 所有可維護內容由後台設定，權限透過 Supabase Auth 和 PostgreSQL RLS 驗證。
- 圖檔保留原始來源，公開網站只提供目前使用的最佳化 WebP。
- **主要在本機連線 Supabase 測試，驗收後才推送店長的公開 GitHub Pages**；不要將尚未完成的功能直接當正式版。

## 各頁面與後台

| 區塊 | 前台 | 後台 |
|---|---|---|
| 01 首頁 | 品牌、最新公告、營業資訊 | 公告、營業時間與首頁精選管理 |
| 02 入館須知 | 已上線狐之館約（五章十四條）；館內照片與空間導覽待完善 | 後續可維護館規與館內內容 |
| 03 服務內容 | 湯屋、特殊體驗、占卜、茶點 | 服務項目、圖片、價格及上下架 |
| 04 人員介紹 | 御守卡、簡介、照片與社群 | 員工資料、照片、特效、分類、排序與公開狀態 |
| 05 值班排班 | 週班表、當日值班人員 | 班表與員工時段維護 |
| 06 茶宴 | 狐之茶宴：御品分類、Gil 價格、數量及可複製點單 | 菜單分類、品項、價格、公開／供應狀態；資料庫 migration 待上線驗收 |
| 07 預約 | 日期、時段、項目與表單 | 時段容量、預約管理與通知 |
