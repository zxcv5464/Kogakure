## 尚需改善及原因

- [ ] 主 JS 仍超過 500 kB：持續檢視共用依賴及真實瀏覽器首次載入時間。
- [ ] 正式資料庫 migration 與 Edge Function 版本未完成獨立驗證：避免程式與資料庫規則不同步。
- [ ] RLS、RPC、Storage 的匿名／員工／管理員隔離仍需實測：前端隱藏按鈕不構成安全保護。
- [ ] iOS、Android、Chrome、Firefox、Safari 的動畫、音樂、圖片與輸入體驗仍需驗收。
- [ ] 公開預約方案、Gil 費用、接單規則與營業公告仍需館方確認。
- [ ] 匿名點單與預約需補可信來源限流、防垃圾提交與請求大小限制。
- [ ] 訂單、預約及帳務需確認資料保存期限、備份與復原策略。
- [ ] 名帖多人編輯、未儲存頁面返回攔截、Storage 孤兒圖片清理尚未完整處理。
- [ ] 外部 BGM 的使用授權、署名需求與第三方連線告知仍需確認。
- [ ] 私人 GitHub 儲存庫與公開網站並存的部署方式尚未定案；現有站點不得因切換可見性而中斷。

## 跨系統變更的必要性

前端、Supabase schema、Storage 權限及 Edge Function 的版本可能彼此獨立。文件中的「程式碼完成」只表示已存在對應實作；**實際部署狀態、資料庫相容性與安全驗證必須分別記錄**。

詳見 `docs/SECURITY_REVIEW_20261117.md` 與各模組變更文件。
