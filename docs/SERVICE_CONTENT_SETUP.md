# 狐隱 KOGAKURE｜服務內容及留影相簿變更必要性

## 已完成變更

- 服務介紹由固定前端內容擴充為 Supabase 管理，保留湯浴、占卜並加入「留影之儀」。
- 以發布狀態及 `sort_order` 控制對外服務；草稿不對訪客公開，降低未完成文案曝光的風險。
- 每個服務支援最多 12 張圖片的有序相簿；多張照片約每 5 秒切換並尊重減少動態效果偏好，背景分頁降低不必要更新。
- 沒有照片時保留清楚的佔位狀態；離線展示資料會標明是示意，正式讀取失敗不偽裝成已成功取得資料。
- 照片只在服務內容確認儲存後才進行上傳；編輯增加未儲存提醒與 `updated_at` 比對，以減少誤傳及多人覆蓋。
- `services.manage` 與服務素材 `service-media` Storage 權限一致；訪客只能讀取允許公開的內容與圖片。

## 修改必要性

- 讓館方能維護服務內容及圖片，不必每次重新修改網站原始碼。
- 保留舊版第一張圖片欄位的相容性，避免單圖版前端因多圖功能而失效。
- 防止草稿外洩、未授權上傳及不同管理員的內容互相覆蓋。
- 刪除或替換服務不自動清理全部舊照片，避免誤刪共享素材；因此後續仍需要安全的孤兒檔案處理機制。
