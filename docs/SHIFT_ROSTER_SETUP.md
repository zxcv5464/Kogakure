# 狐隱 KOGAKURE｜四週滾動值班排班

## 系統行為
- 前台 `/shifts/` 顯示台灣時區的「當週（週一至週日）＋未來三週」，共四週、28 天。
- 每週一（台灣 00:00）日期自動推移一週：上一週移出顯示範圍，最末端補入新一週。頁面維持開啟時，每分鐘檢查日期，切換視窗或重新開啟也會更新。不會建立背景排程、不會刪除歷史資料。
- 日子分成「未公告」（無資料列）、「營業」（is_open=true）及「休館」（is_open=false），**未公告絕不預設營業**。
- 營業日期顯示館方設定的時段、備註與出勤館員的顯示名稱。已經休館／未公告的日子不公開出勤姓名。
- 沒有任何營業日紀錄時，前台全部顯示「未公告」，不會生成虛構營業日或值班人員。

## 管理員／員工後台
- `/admin/shifts/`：正式管理員可設定每一天營業、休館或未公告，並填寫選填的營業時段與備註。每一天按下「儲存開店設定」便會立刻同步資料庫。
- 管理員可透過「我的出勤顯示名稱」（預設婆婆，可自行修改）直接登記或取消自己的出勤，無須額外建立員工帳號。顯示名稱僅用於公開排班，不參與登入身分驗證。
- 管理員仍可透過下拉選單替有效員工帳號加入出勤，或經過確認移除他們的出勤紀錄。
- **任何有效且已登入的員工帳號**都能進入「值班排班」；不需要另行勾選員工的管理權限。員工可以自行填寫「我的出勤顯示名稱」（最多 100 字），在**已設定營業且日期為今天或未來**的日子登記或取消自己的出勤，無法設定營業日期或更動其他員工的班次。
- 預設以員工帳號的 `display_name` 作為出勤名稱，但員工可改成自己的 FFXIV／RP 名稱。出勤名稱**不影響登入身分**；資料庫仍用 `auth.uid()` 與 `employee_accounts.active` 檢查權限。報班後要變更名稱，只需修改上方欄位並按該日「儲存我的出勤名稱」，不用取消原班次。員工只能更改自己的姓名欄位，無法修改班次日期或其他員工 ID。
- 管理員開店日由管理員自主填寫，不預先決定每週幾天、星期幾或時段。新增的一週是空白的「未公告」。
- 備註或時間需要按下該日儲存才會生效；變更週別時請注意尚未儲存的欄位會消失。

## 資料庫、隱私與權限
- SQL `supabase/migrations/20261115_09_rolling_four_week_shifts.sql`：新增 `shift_open_days` 與 `shift_attendance`。另有 `20261115_10_owner_self_attendance.sql` 新增獨立的 `shift_owner_attendance`。`20261115_11_employee_shift_display_name.sql` 允許員工自訂與編輯既有出勤顯示名稱，授權僅限 `UPDATE(employee_name)`（管理員出勤則僅限 `UPDATE(display_name)`）。保留原始班次與既有茶宴、預約、名帖資料。
- RLS：營業日期供所有訪客讀取，只允許正式管理員寫入；員工與管理員的出勤紀錄在營業日才對訪客公開。有效員工只能替自己在已公告營業日新增或刪除出勤。管理員可管理員工出勤，並以 `auth.uid()` 驗證正式管理員身分後，新增或刪除自己的 `shift_owner_attendance`。
- 每個員工每個日期只能有一筆出勤紀錄；參照 `employee_accounts(user_id)`，如果員工帳號被刪除，相關出勤也會跟著清除。
- 前台同時顯示管理員及館員的出勤顯示名稱，不顯示密碼、電子郵件、登入帳號、權限資料。
- 人員名稱在**報班當下**以自行填寫的 RP 名稱保存；若沒有修改，則預設員工帳號的顯示名稱。每一天的紀錄是獨立的，修改已存在的班次名稱需要點該日的「儲存我的出勤名稱」；無須取消報班。輸入框會在本機記住最近使用的名稱（依登入帳號分開），此偏好不是登入憑證。
- 站點只顯示會員**已登記出勤**，不代表館方額外審核過，也不代表當天能接受所有預約。應以館方公告為準。

## 驗收
1. 2026-11-15（週日）顯示 11/9–12/6；2026-11-16（週一）變為 11/16–12/13，總計仍是四週。
2. 沒有設定的 28 天都顯示未公告，員工不可登記出勤。
3. 管理員設定某日營業＋時段，自己以「婆婆」或自訂名稱按下「我會在這天出勤」，員工也可自行報班；旅人看到兩者的出勤顯示名稱。重新整理後資料仍存在，管理員可以自行取消。
4. 員工自訂不同於登入帳號的出勤名稱完成報班，再修改同一天名稱並儲存；確認前台名稱更新且原班次 ID、日期不變。嘗試以員工身分修改開店日、班次 ID 或他人出勤應受到資料庫拒絕；匿名者不能寫入。
5. 管理員設休館時，前台不公開員工出勤；重新開店後保留先前出勤紀錄。
6. 手機版依序顯示四週，並確認「/shifts/」和「/admin/shifts/」直接開啟／刷新不出現 404。
7. GitHub Actions `node scripts/qa-shift-roster.mjs` 自動檢查週一切換、台灣時區、四週／28 天、RLS、前後台和網站路由。
