# 狐隱 KOGAKURE｜四週值班排班變更與必要性

## 已完成變更

- 前台與後台均以**台灣時區當週週一至週日，加未來三週**為顯示範圍，共 28 天；每週自動滾動，不另行改寫歷史出勤資料。
- 沒有營業設定或 `is_open=false` 的日期預設休館，避免向訪客顯示虛構的開店日與館員。
- 前台以七欄月曆呈現營業狀態、活動及出勤摘要，完整資訊由當日詳情承載，改善小螢幕擁擠問題。
- 後台月曆採總覽與單日編輯分離，減少四週長表單造成的閱讀負擔；保留鍵盤焦點及低動態偏好。
- 營業日可帶有選填活動名稱、時段及備註。只有營業日才會對訪客顯示出勤名單。
- 員工出勤顯示名稱與登入帳號名稱分離，可保存常用 RP 名稱，避免公開登入識別；修改常用名稱不會自動改寫歷史班次。
- 管理員本人出勤與員工自行出勤分表或受限保存，維持可追蹤的身分與權限區別。

## 必要的權限界線

- `shifts.manage`：營業日、活動設定及他人班次管理。
- `shifts.attend`：啟用員工僅能管理自己在已公告營業日的出勤，不得改動其他員工或營業設定。
- 匿名者只能讀取允許公開的營業與出勤資訊，不能新增、更新或刪除班次。
- 公開的出勤顯示名稱不包含密碼、Email、帳號名稱與管理權限；出勤登記不代表已通過額外的館方審核，也不保證一定能接受預約。
