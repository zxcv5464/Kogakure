# 狐隱 KOGAKURE｜LOGO 開場與全站背景音樂

## 2026-11-17｜目前 BGM 功能（以下原開場流程持續適用）

- 後台 `/admin/bgm` 可由正式管理員或具有 `bgm.manage` 權限的員工設定音樂：預設來源、已上傳音樂庫、符合格式的 HTTPS 音檔連結，或受支援的 YouTube 來源。
- 上傳檔案由 Supabase `bgm-media` Storage 管理，公開網頁只能讀取允許播放的素材；新增／刪除與設定寫入需通過 RLS。選擇外部來源會向第三方載入資源。
- 維持統一的前台播放器與入館手勢觸發；YouTube 需使用可見嵌入播放器，瀏覽器播放政策及來源限制仍可能影響是否成功。
- 音量目前採預設設定，後台不提供任意音量滑桿。公開頁尾不再保證顯示來源標示；**館方仍須另外核對並保留音樂使用授權與必要的署名**。
- 相關 SQL：`supabase/migrations/20261116_03_bgm_management.sql`、`20261116_04_preserve_bgm_original_filenames.sql`；更完整的移轉與測試見 `docs/SUPABASE_SETUP.md`。

## 2026-11-15｜播放入口合併到原本的 LOGO 開場（歷史流程說明）

- 前台每次**全新載入**網站，直接顯示既有的狐隱 LOGO／KOGAKURE 字樣／「循狐而入，借湯忘憂。」標語。LOGO 淡入結束後，同一個畫面顯示「**進入狐隱・開始播放音樂**」按鈕，**不再新增第二個音樂播放頁面、遮罩或彈出視窗**。
- 旅人點擊這個按鈕時，事件處理程序立即呼叫原本全站播放器的 `HTMLMediaElement.play()`，**同步執行於該次使用者點擊**；之後才啟動原本的淡出與首頁／目前直接連結頁面的淡入，不改動館內原有頁面與資料載入方式。
- Chrome、Safari 對有聲自動播放有限制，無法從程式強制繞過；整合原有 LOGO 開場與「入館」按鈕，可自然取得啟動音樂所需的使用者操作。如果官方串流音檔無法連線或播放請求被拒，**網站仍可進入**，旅人可透過頁首 BGM 按鈕再次嘗試。
- 未經後台另行選擇時，預設使用既有 BGMer〈みやびごころ〉串流，音量約 24%；也可改為後台設定的上傳／外部來源。一般音檔跨首頁、館約、服務、名帖、值班、茶宴及預約時維持播放；實際仍受來源可用性與瀏覽器限制影響。
- 頁首 BGM 開關依舊可停止或重新播放；當次瀏覽停止後切換頁面保持停止。新的一次整頁重新載入仍會顯示 LOGO 開場並重新請求入館啟動，不保留上一次靜音選擇。
- 如果偏好「減少動態效果」，保留**無動畫的 LOGO 與入館按鈕**，不會因動畫設定而隱藏進站入口。對話式開場的焦點會移至入館按鈕，確保鍵盤可操作。
- 管理員後台不出現前台品牌開場，也不播放前台 BGM。**網站頁尾目前不再固定展示音樂授權文字**；選用上傳或第三方音樂時，請依實際授權條款另行提供必要標示。

## 檢查

- GitHub Pages 建置：`npm run build`
- 全站音樂與開場檢查：`node scripts/qa-site-bgm.mjs`
- 手機／桌機實際操作：新訪客看到原始 LOGO → 原畫面按「進入狐隱・開始播放音樂」→ 網站淡入、開始播放 → 換前台頁面不重置音樂 → 頁首 BGM 可停止及重新播放 → 重新載入後重新顯示原始 LOGO 開場。
- 當 GitHub Actions 部署同一個 run 曾重新執行而產生多個同名 `github-pages` artifacts 時，改用全新工作流程執行，避免 GitHub Pages 找到重複檔案。
